# Skill: apply_rules

Gọi tool `apply_rules` (rule engine deterministic) với metadata đã trích + nội dung văn bản.
Rule engine chạy rule cứng theo thứ tự ưu tiên và trả kết quả 4 trường:
Đơn vị xử lý chính / Phối hợp xử lý / Lãnh đạo theo dõi / Hạn thực hiện.
Chỉ dùng model reasoning cho phần rule không match rõ ràng.
